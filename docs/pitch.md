# Zeraphim: Ascension - Pitch

## What is Zeraphim: Ascension?

A minimalist GameFi experience built natively on OneChain. Players embark on quests across three divine paths, earn rewards, open loot boxes, and evolve their Wings NFT through on-chain progression.

## Problem

Most GameFi projects are either too complex to demo in 3 minutes or lack meaningful on-chain interaction. They often have a landing page and an NFT mint, but no real gameplay loop.

## Solution

Zeraphim: Ascension delivers a complete gameplay loop in under 60 seconds:

1. **Choose a Path** - Select from Valor, Wisdom, or Grace quests
2. **Complete Quests** - Earn XP, Divine Shards, and Loot Tickets via on-chain transactions
3. **Open Loot Boxes** - Discover random rewards from the divine treasury
4. **Evolve Wings** - Progress through 3 tiers of Wings NFT evolution
5. **Compete** - Climb the leaderboard against other players

## Why OneChain?

- Move-based smart contracts provide safety and composability
- Fast finality for responsive gameplay
- Native support for on-chain game state

## Technical Highlights

- 4 Move modules: quest, lootbox, wings, types
- Backend indexer for real-time leaderboard
- Minimalist dark UI with professional design
- Complete transaction flow with toast feedback
- Streak mechanics for player retention
- Challenge objectives (24h quests, loot cadence, streak keeper) for deeper replay loop
- Non-cash reward design: no wagering, no cash-in/cash-out gambling loop

## On-chain Proof

- Minimum 3 successful transactions demonstrable
- All game state stored on-chain via UserState resource
- Events emitted for every action (indexer-compatible)

## Roadmap
