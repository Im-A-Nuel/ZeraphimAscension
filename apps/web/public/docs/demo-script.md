# Demo Script - Zeraphim: Ascension (3 minutes)

## Setup (before demo)

- Frontend running on deployed URL
- Move contracts deployed on OneChain testnet
- Backend API running with indexer active
- Wallet funded with OCT via faucet

## Demo Flow

### 0:00 - 0:30 | Introduction

- Open the landing page
- Show the clean, minimalist design
- Click "Connect Wallet"

### 0:30 - 1:00 | Dashboard Overview

- Show the Profile Panel (Level 0, 0 XP, 0 Shards)
- Point out the Quest Board with 3 paths: Valor, Wisdom, Grace
- Show Wings card (no wings yet)
- Show Loot Box panel (0 tickets)

### 1:00 - 1:30 | Complete a Quest

- Select a quest from the Valor path
- Click "Complete Quest"
- Show pending transaction toast
- Show success toast with XP and Shards earned
- Point out updated Profile Panel

### 1:30 - 2:00 | Open Loot Box

- Show the earned Loot Ticket
- Click "Open Loot Box"
- Show transaction confirmation
- Reveal the reward (Shards bonus)

### 2:00 - 2:30 | Mint and Evolve Wings

- Click "Mint Wings"
- Show Wings card updated to Tier 1
- Complete more quests to accumulate shards
- Click "Evolve Wings" when requirements are met

### 2:30 - 3:00 | Leaderboard and Proof

- Navigate to Leaderboard page
- Show user ranking and score
- Navigate to Activity page
- Show transaction history
- Show explorer links for on-chain proof
